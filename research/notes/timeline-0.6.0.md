# 0.6.0 七参数时间轴

2026-10-20。主界面改为七条独立参数轨道和底部速率轨道：X、Y、Z、摄像机水平角度、俯仰、横滚、缩放。

## 时间模型

- 主界面固定使用 `camera_clock=replay`；旧工程显式使用 shooting 时先形成绑定模式草稿，保存或在主界面播放前保存后生效。不静默覆盖原文件。
- 摄像机键的 `time_sec` 表示片段内对局相对时刻，原点仍由启动播放时暂停的回放位置确定。本版不实现游戏回放任意跳转或绝对事件定位。
- 上标尺显示拍摄时间，下标尺显示对局相对时间。可切换主标尺；在拍摄标尺上变速会移动摄像机键的显示位置，不改动其对局时间戳。
- 速率键保留现有原生接口的拍摄进度语义。原生镜头驱动仍取已验证的回放推进时间；速率积分、反解和离线预览使用同一分段线性/平滑函数。实际拍摄长度 = 对局片段长度 / 平均倍率。
- 显式“战斗暂停，仅运镜”继续支持旧有独立拍摄流程，界面会标出该例外。

## 工程与插值

- JSON 新增可选 `camera_tracks`，七个标量轨道各自保存时间和值。传统全机位 `keyframes` 是七轨时间并集处的兼容投影；轨迹求值及原生 120 Hz 编译直接采样原始七轨。
- XYZ 平滑模式使用带时间切线的三次 Hermite 曲线，不保证空间匀速；直线模式用参数线性插值。角度按显式标量插值后组合四元数，支持显式输入整圈转动；旧四元数导入时水平角度和横滚按最短相邻角差展开。
- 独立轨道模式遵守各键时刻，不能同时启用全路径弧长重排。旧完整机位表改为只读参考。
- 截取新构图同时写入七个参数轨道；悬浮窗的整段重定时同步变换七轨，改名保留轨道；原生 DLL 未修改。

## 编辑行为

- 菱形键拖动、Shift 多选、空白框选、参数精确输入、单轴增删、帧/跨轨时刻吸附、标尺缩放与横向滚动。
- 100 步撤销/重做，保存后仍可撤销；Delete、Ctrl+Z、Ctrl+Shift+Z、Ctrl+S，方向键按所选时间轴帧率逐格预演。
- 草稿通过独立只读求值接口预演，不保存、不接管游戏；仅显式游戏播放使用既有 Hook。播放期间锁定编辑，播放头跟随联动进度。
- 24/30/60 fps 是编辑标尺与吸附频率，不是游戏回放数据帧率或确定帧导出承诺。
