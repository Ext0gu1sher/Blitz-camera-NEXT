# 0.9.4 用户反馈修复验收

日期：2026-10-23。游戏控制适配范围仍为 Steam 国际版 11.21.0.1235。

## 行为

- 全局 Ctrl+Alt+F8 记录当前游戏镜头的七项摄像机属性。模式一取编辑器播放头，模式二取游戏暂停时刻；默认不替换已有点。记录前经原生桥接等待草稿及视图保存，失败时取消。Ctrl+Alt+F9 显隐悬浮窗；两键均支持 F7–F12 设置，冲突时回滚且明确提示。
- 编辑器预览从当前播放头至全片结束，循环覆盖全片；工作区内保留速度曲线，区间外按正常速度。游戏内工作区间限制保持。
- 游戏窗口最小化时悬浮窗自动隐藏，恢复时还原布局及折叠状态；手动隐藏状态单独保存，完整工作台不受影响。
- 模式二解析 Type 8 / method 48 / wrapper 3 的 arena period=3 事件，使用事件原始时刻减 record 0x11 回放原点。该受支持版本布局中 method 48 为 Avatar arena 更新；固定上游解析和实体路由研究的样本没有车辆实体冲突记录。仅接受明确事件，不以固定倒计时推断。
- `replay_keyframe_start_seconds=null` 默认自动，数值为从编辑器零秒开始的赛前长度（0–3600 秒）。绑定回放但未识别事件时，提示先手动设置。设置写在应用设置中，保存后即时生效。
- 时间轴七条摄像机轨道显示赛前背景和比赛开始边界。新增、移动、数值编辑、撤销重做、预览镜头记录、实机记录及全局记录均执行校验。旧项目已有早期点可加载、原位修改和删除；速度轨道可继续编辑。
- 服务端从可用的真实文件解析并缓存事件，以路径、文件大小、修改时间和预期内容标识区分；本地文件不可读时使用已保存的事件元数据。旧项目自动补读，不改已有机位时间。真实文件与保存内容标识冲突时不采用该文件的开始事件。

## 验证

`python -X utf8 -B -m unittest discover -s tests -q`：459 项通过。包含事件 framing、时钟原点、阶段区分、损坏与缺失事件、手动设置、每轨关键帧校验、实际捕获时刻、项目新建和迁移、缓存身份、草稿及写入失败等。

独立浏览器与集成界面验收通过：

- `tools.test_speed_window_ui`：入点前、出点后开始，跨出点，至全片末尾停止及循环；无游戏接口请求。
- `tools/test_keyframe_guard_ui.cjs`：逐轨添加、边界、拖动、数值、撤销重做、未知事件、模式一放行。
- `tools.test_keyframe_guard_app_ui`：实际文件绑定，19.25−4.25=15 秒事件；保留旧点、边界新增、赛前拒绝、设置覆盖后新增与重载。
- `tools.test_settings_ui`：默认自动，手动 0 秒与小数、重载持久化、恢复自动及原目录设置功能。
- `tools.test_desktop_controls`：真实 Windows 两键注册、重复键、外部占用回滚、无悬浮窗时发送一次记录请求；原生窗口最小化恢复、手动隐藏、折叠及多次显隐；记录前保存，保存失败取消。
- `tools.test_overlay_ui`：完整七轨、工作区间、属性与速率点 Ctrl+点击、数值和拖动、模式切换、边缘滚动、撤销重做、持久化及回放启动回归全部通过。

原生布局和桥接复核通过：830 像素悬浮窗内全部快捷键设置可见；工作台与悬浮窗分别修改后，另一窗口显示原生实际新值。报告 `output/archive/2026-10-27/verification/desktop-controls-acceptance/layout-bridge-result.json`。
