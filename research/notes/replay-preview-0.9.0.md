# 模式二离线预览 0.9.0

实现日期：2026-10-21。该预览不连接游戏进程、不装载 Hook、不启动游戏。模式二使用原有对局时间轴和变速积分；模式一保留独立镜头时间及网格。

## 操作

选择模式二，点击“载入回放预览…”，载入国际版回放。文件和全片长度绑定为草稿，摄像机关键帧不重排；关键帧超出新文件长度时拒绝绑定。已有项目有回放路径则自动载入。地图和车辆资源只读转换自本机 Steam 客户端，首次缓存至 output/replay-preview-cache。切换文件会自动核对地图编号与名称，不使用固定地图。

在场景观察中左键旋转、右键平移、滚轮缩放；拖动原有时间轴查看车辆和轨迹。镜头画面按 16:9 使用七轨实际求值。记录预览镜头会在播放头一次加入七项属性，已有关键帧时提示，不覆盖。保存后沿用原有游戏内执行。

## 固定来源与实现

解码：WoT-Blitz-Agent v0.4.9，commit 8dcec2c6463f23116871157ef6d64985875efd67 的 WASM，在本地 Worker 运行。车辆身份、可见区间、运动采样、地形和材质装配：WotbTools commit 11d0d519aba2afedcae3d49365b0bfd1a4b5c76d。地图/车辆导出使用同一 Agent 的固定 Python 导出器。绘制为 Three.js 0.185.1，全部资源随包，不用 CDN。

replay_preview.py 用完整内容哈希绑定回放、不透明地址绑定资源。换文件使旧地址失效，转换串行执行，旧任务不能覆盖新来源。preview_assets.py 按客户端哈希、资源路径/大小/修改时间、地图注册和车型元数据建立缓存。只核对 512/16 高度场、居中正方形边界和明确地图变体；不支持时明确报错。高度场保持上游 layout 2 的解块与角点镜像，不是普通图片翻转。

世界坐标为 DAVA Z 向上，场景映射为 (-X, Z, Y)。JS 的位置 PCHIP、角度、缩放和缓动与 Python ScalarTrack 保持一致。镜头基底生成同一四元数，水平缩放按 16:9 转为垂直投影角。记录观察镜头用逆变换，水平角度和横滚选择接近现有轨道的等价角度。

## 时间和画面边界

游戏相机时钟与录像包时钟尚未独立对齐，不自动减去倒计时。界面提示需用同一事件核对；显示偏移按文件哈希保存，只影响车辆重建，不改摄像机关键帧或游戏时间。本轮 canal 文件为国际版 11.21；换图测试的 plant 为国际版 11.20，使用 11.21 资源，不等于旧版本画面完全一致。

只重建有位置和可见记录的车辆，未知搭载模型用方块。材质、植被、光照与游戏不同；不重建开炮烟火、悬挂或破坏状态。当前未接入额外枪管俯仰限制的二次解析，不用于炮口级精确构图验收。预览不校正游戏碰撞。许可及元数据权利见 blitzcam/preview_vendor/NOTICE.txt，便携包不含本机转换出的地图、模型、贴图。

## 自动检查

tools/verify_replay_preview.py 使用隔离项目与隐藏浏览器，禁止游戏连接和启动。检查真实地图/车辆可绘制、60→75→60 位置一致、镜头与 Python 求值一致、固定倍率/曲线联动、一次记录七轨、模式一隔离。--additional-replay 检查换图。

tools/verify_desktop_package.py --preview-replay 在独立中文和空格目录解压，以便携 Python 和隐藏原生 WebView2 检查压缩贴图、回放场景、回拖、导出及退出。自动检查证明执行和数据链路，游戏与预览的视觉/时间对应仍需人工核对。
