# 速度面板直接编辑（2026-10-22）

主速度图按实际宽高生成坐标系，修复固定比例 SVG 居中造成的大面积留白。点、手柄和文字保留正常屏幕尺寸，倍率及拍摄进度刻度铺满图表。工作区边界用虚线标出，区间外曲线保留。

新增 speed-editor.js，所有修改由时间轴 Editor 的文档和撤销栈持有。Ctrl+左键及双击添加指定倍率的点；工具栏加号在播放头按原曲线求值，并以 de Casteljau 精确分割分段，保持速率函数与积分。拖动一次只提交一个撤销记录，Esc 或指针取消恢复原文档。首尾进度固定且不可删除。支持方向键、Shift 锁定方向、Alt 微调、精确数值和单段过渡。

选中点展示相邻变速段的贝塞尔手柄。速度点可保存出段 ease: [x1,y1,x2,y2]。横坐标有序且限制在分段内；纵坐标按分段端点倍率归一化，可超过 0–1，但实际控制点倍率必须在 1/16×–1× 内。相同倍率的段为匀速。全局过渡选择清除分段覆盖；单段可跟随全局，或使用平滑、线性、贝塞尔。

Python、浏览器和原生时钟统一通过二分反解三次曲线的横坐标，并解析积分 y(t)·x'(t)。完整时长、工作区裁切、续播和首尾延伸使用相同积分，沿用原曲线时间范围。SpeedPoint 共享结构增加四个坐标和自定义标志；清单核对新的结构大小及模块哈希。

撤销快捷键现在先于按钮和下拉框过滤处理。速度数值输入提交后同样可撤销；其他文本输入保留文本撤销。撤销、重做尽量保留仍存在的选中点。

验证覆盖 287 项 Python 测试，原生独立进程的贝塞尔完整播放与工作区切片，以及 tools.test_speed_editor_ui、tools.test_speed_window_ui、tools.test_overlay_ui。直接编辑验证包含响应式布局、Ctrl 加点、精确补点、拖动撤销、输入和下拉框撤销、手柄、取消、工作区和保存重开。截图位于 output/archive/2026-10-27/verification/speed-editor-acceptance。
