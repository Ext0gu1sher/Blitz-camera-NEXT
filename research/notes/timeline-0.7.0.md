# 0.7.0 整场回放绝对时间轴

2026-10-20。默认标尺改为对局时间，范围从 0 到回放总长，不随首尾摄像机关键帧缩成相对时间片段。

## 时间与播放

- `replay_timeline` 保存绝对对局时间基准、全片长度、入点、出点。七参数 `time_sec` 使用当前读取器的对局时间；缩放、变速及改变工作区间不会自动重排摄像机键。
- 只读读取所选回放 ZIP 的 `meta.json.battleDuration`，元数据上限 64 KiB。可粘贴回放路径读取长度，也可手动填写。连接时尝试读取进程启动参数中的回放路径；它不保证对应后来在游戏内切换的回放，界面显示来源供核对。没有该来源时明确标出长度待确认，不根据最新文件猜测。
- 旧工程机位时间原样保留，载入主界面形成绝对时间草稿，保存后才持久化。“平移旧机位到当前时刻”显式整体平移；“当前回放设为入点”只改变区间。
- 保存实机构图时以后端当次暂停快照的对局时间为准，包括悬浮窗。
- 全片可编辑，实机仅编译工作区间。固定倍率从区间内实际暂停时间执行到出点，原轨迹仍按全局时间求值；不把全片重排到当前时刻。曲线播放要求从入点开始，避免中途启动而重置速度曲线。
- 原生 Hook / DLL 未改。窗口编译把对局时刻转换为原生相对时间，再由已有回放时钟驱动。单次播放仍受 0.5–120 秒及实际拍摄时长限制，完整工程不被截短。
- 不支持任意回跳、自动定位或战斗倒放。倒序运镜限战斗暂停模式，仍是独立拍摄例外。
- 速率曲线保留原生拍摄进度语义，在选定工作区间内显示对应对局时刻；尚非任意全片绝对速率事件表。倍率变化不改变摄像机绝对时间键。
- 文件元数据只证明所选文件总长，不证明回放数据完整解码，也不独立证明其为当前游戏回放。

## 编辑与验证

- Alt＋滚轮以鼠标位置缩放；连续滚轮保留逻辑锚点，避免滚动条取整累积漂移。增加“区间”视图，长标尺只绘制可见区域。
- 轨道空白处左键拖框，两个方向均可跨轨选择，Shift 追加；整组拖动保留间距。标尺拖动只预演，没有调用游戏 seek。
- 悬浮窗采用实际对局时间，禁用旧全轨迹比例重定时，保留主工作台区间。
- 208 项 Python 测试通过，覆盖绝对时间持久化、全片边界、实际时间捕获、窗口全局求值和原生表时间、错误区间、曲线起点与只读文件元数据。
- 页面验收通过：真实鼠标事件测试 Alt 滚轮、双向左键框选、Shift 追加、6 键拖动、变速不移动摄像机键、空白处预演不跳转游戏、读取文件、保存重载、区间播放。使用合成回放和假的播放执行器，没有操作实际游戏。

- 本轮没有启动真实游戏运镜、写内存或注入；新绝对时间联动尚待实机画面验收。
