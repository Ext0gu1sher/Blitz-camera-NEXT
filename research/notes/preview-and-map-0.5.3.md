# 0.5.3 速度预览与真实地图可行性

核对日期：2026-10-20。客户端为此前已适配的 Windows Steam 11.21.0.1235。本轮不操作游戏，不修改客户端文件或游戏 Hook。

## 已实现

- 两个界面均有战斗速度图，显示拍摄进度、倍率、拍摄耗时与战斗推进量；固定倍率、速度曲线、战斗暂停均有对应图示。
- 离线预演依据 `position_replay_clock.h::clock_integral` 的分段解析积分计算时间。平滑倍率使用三次 smoothstep，积分为 `u³−u⁴/2`。拍摄时钟直接驱动镜头；回放时钟以积分驱动镜头，反求拍摄进度时二分求解。游戏内倍率是每个 tick 的平均倍率；离线读数是连续曲线的理论值，不重现粒子、音频或回放画面。
- 实际接管期间，图的指示和数值使用已有 Hook 报告的拍摄耗时、倍率与战斗推进量。镜头反向不会反转战斗速度曲线。
- 悬浮窗 3D 新增旋转、平移、缩放、复位、坐标轴、辅助网格和机位向网格的高度投影。辅助网格不是地形或碰撞面。
- 修复悬浮预览拖动进度条时，暂停回调先刷新输入值而导致位置被重置的问题。

## 本地地图证据

运行 `python -X utf8 -B research/scripts/inspect_map_assets.py --map-id 11_plant_pn`，仅读安装目录，在研究目录保存高度点及校验记录。此脚本使用已有研究环境的 lz4，工作台不增加该依赖。

文件位于 `C:\Program Files (x86)\Steam\steamapps\common\World of Tanks Blitz\Data\3d\Maps\11_plant_pn\`：

| 文件 | 本次观察 |
|---|---|
| `landscape\height_test.heightmap.dvpl` | CRC 验证、解压后 524296 字节；前两个小端 uint32 为 512、16，长度等于 `8+512×512×2`；按 16×16 分块重排得到 262144 个 uint16 高度点，原始范围 7137–57020 |
| `11_plant_pn.sc2.dvpl` | CRC 验证、解压后 7224875 字节；开头 `SFV2`、版本值 48；包含该高度图的相对路径引用 |
| `11_plant_pn.scg.dvpl` | CRC 验证、解压后 20392124 字节；开头 `SCPG`；尚未解析顶点、索引或模型实例 |

源文件路径、SHA-256 和证据：`research/builds/11.21.0.1235/map-assets/11_plant_pn/evidence.json`。重排后的网格在同目录 `height-grid.json`。原始高度尚未标定，不能直接当作世界 Z。

历史公开 DAVA [Heightmap::Load 源码](https://github.com/smile4u/dava.engine/blob/master/Sources/Internal/Render/Highlevel/Heightmap.cpp) 采用尺寸、块尺寸及 uint16 分块读取，与本次头部和长度一致，是格式判断依据。该源码不等于当前客户端源码，不能默认全部场景格式兼容。[Landscape::Load 源码](https://github.com/smile4u/dava.engine/blob/master/Sources/Internal/Render/Highlevel/Landscape.cpp) 从场景读取高度图路径和 bbox 后构建地形，说明还需场景范围与变换才能恢复世界坐标。

## 建议的地图路线

有可验证的数据入口，值得继续。优先使用本机资源构建静态预览，无须先多角度截图重建。

1. 只做 plant 一张地图：解析当前 SC2 的地形 bbox、实体及父级变换、范围和高度比例；用已知机位和至少三个固定地标核对 XY 方向、尺度和 Z 偏移，不能仅凭画面大致吻合。
2. 对齐通过后，将高度点降采样为地形网格，叠加路径、机位编号和视锥。此阶段可观察相对山坡、地面的高度；高度场不表达建筑、桥洞或悬空结构，也不代替碰撞检测。
3. 再解析 SCG 顶点、索引和 SC2 模型实例变换，加入建筑与桥梁；先采用纯色几何或线框，再按需要处理材质、贴图、LOD。不承诺复现游戏光照、阴影、植被动画或破坏状态。
4. 地图 ID 和源文件哈希共同标识本地转换缓存；更新资源后重建。缓存留在本机，不把游戏资产打包发布。转换属于独立适配层，不需要修改镜头控制 Hook。

本轮尚未证明当前版地形 bbox/实体变换解析、世界坐标对齐或建筑几何读取成功。UI 没有伪造的“真实地图”，也没有把原来的四个机位放到未经标定的高度点上。
