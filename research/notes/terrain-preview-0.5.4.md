两份文件通过 DVPL 的压缩长度、CRC 和解压长度核验。场景是 SFV2 版本 48；描述区后为 KA2 字符串表与根归档。当前只读解码器验证整个场景 7,224,875 字节全部消费完毕、字符串哈希无冲突、嵌套归档声明长度一致、根节点数量一致。解出 7,684 个数据节点、2,622 个根实体及场景组件。KA2 的具体编码由本地字节核对，不声称历史 DAVA 代码直接支持此格式。

唯一的 `hmap` 位于 `#hierarchy[32].components.0001.rc.renderObj`，该归档在解压后的场景偏移 **1,471,641**：

```
##name = Landscape
hmap = landscape/height_test.heightmap
bbox = (-300, -300, 0) .. (300, 300, 80)
```

它是顶层实体 `name=Landscape, id=4`。同一实体的 TransformComponent：本地与世界 translation 均为 `(0,0,0)`，scale 均为 `(1,1,1)`，rotation 均为 `(0,0,0,1)`；不存在需要叠加的父实体变换。当前转换器遇到非单位变换即拒绝，不擅自平移、翻转 Y 或放大 Z。

高度图为 512×512、16×16 块存储的 uint16。采用历史公开 [DAVA Heightmap::GetPoint](https://github.com/smile4u/dava.engine/blob/master/Sources/Internal/Render/Highlevel/Heightmap.h) 的映射：

```
X = -300 + x/512 * 600
Y = -300 + y/512 * 600
Z = raw/65535 * 80
```

注意分母是 size=512，不是 511。取到边界 x/y=512 时夹取最后一个高度样本。离线探针：

| 原始网格点 | raw | 映射位置 |
|---|---:|---|
| (0,0) | 9757 | (-300,-300,11.910582) |
| (256,256) | 22849 | (0,0,27.892271) |
| (511,511) | 34975 | (298.828125,298.828125,42.694743) |

这些是格式与资源坐标探针，**不是游戏画面的三个地标实测**。没有把历史公式在当前运行版的行为、与画面最终对齐或地图自动识别写成已验证。

## 实现

- `research/scripts/scene_archive.py`：有长度、深度、数量限制的只读 KA2 解码；未知类型拒绝。
- `tools/build_terrain.py`：仅接受本次核对的两份资源哈希，提取地形范围与变换，将高度场降采样到 65×65。命令：`python -X utf8 -B -m tools.build_terrain`。
- 本地转换缓存：`output/map-cache/11_plant_pn.json`。保留源哈希、原始分辨率、世界范围、变换、三个探针和验证状态，不打包发布游戏资产。
- `blitzcam/terrain.py` 与只读 `GET /api/terrain/11_plant_pn`：校验网格、坐标范围及当前源文件哈希。资源变化或缺失时停用该地形，不静默套用旧数据。
- `terrain-preview.js`：两界面共享的纯前端地形网格、明暗绘制与缓存。路径播放时复用地形栅格，旋转/缩放/平移时才重绘；不逐帧重新解压或解析地图。
- 悬浮窗、完整工作台：手动选择“plant 地形”，支持整张地图/聚焦轨迹、已有三维旋转和缩放；叠加轨迹、机位编号、当前视锥和机位到高度场的虚线。轨迹覆盖显示，不提供地形遮挡判断。
- 地形选择与视图不改变项目 JSON、关键帧或实际游戏状态。默认仍为示意网格；用户选择 plant 后明确显示“手动选图，须与回放一致”。没有猜测当前回放地图。

## 验证与边界

自动界面验收使用合成机位、模拟播放器与本机 plant 资源，完全不操作游戏或用户桌面。验证两个界面的地形加载、范围切换、网格恢复、资源错误时撤掉旧地形、项目与运镜状态不变，以及原有速度预览、双向播放请求和停止。Python 单元测试验证资源变更、非法地图路径、无效高度、缺失缓存和同源 API 防护。

当前可用的是**资源坐标地形预览**。还需要在获准操作游戏后，用至少三个分散地标或可靠运行时地形采样核对当前引擎的 XY 方向、比例与 Z 映射；验证标记 `visual_alignment_verified` 保持 false。建筑、桥梁、树木、碰撞、材质与游戏光照均未加入。地形插值不是游戏碰撞或完整关卡几何，不据此修正运镜路径。
